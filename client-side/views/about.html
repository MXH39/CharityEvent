💰 What we do

We plan and run charity events — fun runs, gala dinners, silent auctions and concerts — and direct every dollar raised to education, elderly care, animal protection and disaster relief programs.

💻 How this website works

A Node.js / Express REST API retrieves and manipulates the charity events stored in MySQL. The client website and the staff admin portal are both AngularJS single page applications that consume that API.

🌤️ Live weather

Every event stores its latitude and longitude, which lets us request a real weather forecast for the day of the event from the external Open-Meteo API.
